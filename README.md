# QERRA-v2

**Hybrid Quantum-Classical Ethical Decision Engine**

Live API: https://qerra-v2-api-production.up.railway.app/docs

QERRA-v2 is an open-source project exploring the combination of classical AI safety techniques with quantum-inspired methods to support ethical decision-making in high-stakes environments, with a long-term vision for safe human–humanoid robot collaboration.

### Current Status (April 2026)
- Working classical `/analyze` endpoint with nuanced scoring and reasoning
- Experimental hybrid `/quantum_analyze` endpoint using a 6-qubit simulator
- Successfully executed an 8-qubit W-state on real IBM quantum hardware (January 2026)
- Early-stage research and demonstration project

### Key Features
- Transparent scoring (0.25–0.95) and reasoning for every decision
- Contextual awareness for ethical dilemmas (e.g. financial pressure, personal hardship)
- Sacred ethical vectors guiding the system
- Fully open source under AGPL-3.0

### Important Note
This is an early-stage research project. The quantum component is currently simulated and serves as a placeholder for future principled quantum integration. The system is not yet validated for safety-critical applications.
