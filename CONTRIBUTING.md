# Contributing to QERRA-v2

Thank you for considering contributing to QERRA-v2!

This is a solo, early-stage project developed by Marussa Metocharaki under significant personal constraints. I welcome help, but I ask for your understanding and patience.

## What is welcome right now
- Bug reports and clear reproduction steps
- Improvements to documentation (README, Whitepaper, API-DEMO.md)
- Additional test cases for the /analyze endpoint
- Suggestions for clearer code comments or structure
- Feedback on the ethical framework (SEMEV-12) and safety kernel
- Small, focused pull requests that fix or improve existing functionality

## What is currently out of scope
- Major architectural changes
- New ML models or heavy dependencies
- Production-ready quantum hardware integration (this is still experimental)
- Large refactors without prior discussion

## How to contribute
1. Open an issue first to discuss your idea
2. Fork the repository
3. Create a small, focused pull request
4. Reference the issue in your PR description
